# 📁 FileMaster

### ⚡ Your Files. Your Control.

**🚀 A modern, powerful, and user-friendly Windows file management application.**

FileMaster is an all-in-one desktop application designed to make file management, organization, storage analysis, and everyday file operations easier, safer, and more efficient.

Instead of switching between multiple Windows utilities, FileMaster brings essential file management tools together in one organized workspace with a modern interface, intuitive navigation, and support for both Arabic and English.

🎯 **Our Mission:** Give users greater control over their files, better visibility into their storage, and a smoother everyday experience.

## 🌟 Overview

Managing files on a Windows computer can become complicated when files are scattered across multiple drives, folders, and locations.

Finding large files, organizing downloads, identifying duplicates, understanding storage consumption, and cleaning unnecessary files can take time and require several different applications.

**FileMaster brings these essential tasks into one application.**

### 🎯 Our Core Principles

- 🧩 **Simplicity:** Make common file operations easy to understand and perform.
- 🎮 **Control:** Give users visibility and control over file operations.
- 🛡️ **Safety:** Prioritize previews, confirmations, and recoverable operations wherever supported.
- ⚡ **Efficiency:** Reduce repetitive tasks and simplify everyday file management.

## 📥 Installation

There are two ways to get started with FileMaster.

### 🥇 Option 1: Windows Installer (Recommended)

1. 🌐 Open the GitHub Releases page.
2. 📥 Download `FileMaster-Setup.exe`.
3. 🖱️ Run the installer.
4. 📋 Follow the installation instructions.
5. 🚀 Launch FileMaster from the Start Menu.

### 🥈 Option 2: Portable Version

Prefer not to install the application?

1. 📥 Download `FileMaster-Portable.zip`.
2. 📦 Extract the ZIP archive.
3. 📂 Open the extracted folder.
4. 🚀 Run `FileMaster.exe`.

The portable version is intended for users who prefer to run FileMaster without the standard installer.

## 🔐 Security and Privacy

FileMaster is designed to help users manage their local files with greater visibility and control.

### 🛡️ Safety Principles

- 👀 Make file operations understandable.
- ⚠️ Require appropriate confirmation for destructive actions.
- 📋 Allow users to review cleanup items.
- ♻️ Use supported recovery mechanisms.
- 🔒 Store application settings and local data in the application's user data location.

### ⚠️ Important Security Notice

FileMaster is currently unsigned.

Windows SmartScreen or other security software may display a warning when launching the installer or application.

📥 Always download release files from this official GitHub repository.

**Remember:** Review operations carefully before confirming changes to important files.

## 🧪 Quality Assurance

FileMaster includes automated tests and release validation checks.

### ✅ Testing Areas

- 🎨 Application resources.
- 🌍 Translation consistency.
- 🧩 Required modules.
- 📂 Application pages.
- 📦 Packaged application integrity.
- 🖥️ Command-line self-test behavior.
- 🔐 Release artifact consistency.

### 🧰 Self-Test Commands

Run the standard headless test:

```bat
FileMaster.exe --self-test
```

Run the deeper interface-related checks:

```bat
FileMaster.exe --self-test --deep
```

The standard self-test is designed to run without opening the graphical interface.

The deep test builds interface components in an offscreen environment.

These checks complement, rather than replace, testing on a real Windows computer.
